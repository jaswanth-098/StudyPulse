# StudyPulse
## Intelligent Student Productivity and Performance Analyzer

StudyPulse is a Python micro project for tracking study sessions, examination results, assignments, and student productivity.

### Features
- Academic dashboard
- Study session tracking
- Exam result management
- Assignment management
- Analytics and charts
- Rule-based study recommendations
- CSV and ZIP data export

### Technologies
- Python
- Streamlit
- SQLite
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Installation
1. Install Python.
2. Install dependencies using: pip install -r requirements.txt
3. Run the application using: streamlit run app.py
4. Open http://localhost:8501 in your browser.
